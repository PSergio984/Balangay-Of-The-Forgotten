## 📖 About

**Balangay of the Forgotten** is a creative adventure game where players become the **Pinili**, embarking on a quest in the afterlife to reclaim the lives and truths of their gods. Success depends on testing your party's **strength**, **unity**, and **tactical choices** against powerful bosses and trials.

### Key Features
- 🗡️ Tactical party-based combat
- 🐉 Boss battles inspired by Philippine mythology
- 🎭 Four unique character roles with distinct abilities
- 📜 Story-driven progression through the afterlife
- ⚔️ Strategic role synergy and party composition

## 🛡️ Character Roles

*"Sa Balangay, ang tanging 'di nilimot ay ang alamat."*

| Role | Primary Function | Key Stats |
|------|-----------------|-----------|
| **Mandirigma (Damage)** | Melee DPS | ATK, HP |
| **Bagani (Tank)** | Protector/Defender | HP, DEF |
| **Babaylan (Healer)** | Support/Caster | MAG, HP |
| **Mangangayaw (Ranged)** | Ranged DPS | ATK, HP |

### Role Details

<details>
<summary><b>Mandirigma</b> - The Warrior</summary>

High damage melee fighter focused on eliminating threats quickly. Excels in sustained damage output.
</details>

<details>
<summary><b>Bagani</b> - The Defender</summary>

Frontline tank that protects the party. High HP and defense make them ideal for absorbing damage.
</details>

<details>
<summary><b>Babaylan</b> - The Shaman</summary>

Support healer who keeps the party alive. Uses magic to heal wounds and provide buffs.
</details>

<details>
<summary><b>Mangangayaw</b> - The Ranger</summary>

Ranged damage dealer who strikes from afar. Provides consistent damage while staying safe.
</details>

## ⚙️ Installation

### System Requirements
- **OS:** Windows 7/8/10/11
- **Processor:** Dual Core 2.0 GHz+
- **Memory:** 4 GB RAM
- **Storage:** 983 MB available space

### Installation Steps

1. **Download** the ZIP file from [Latest Release](https://github.com/PSergio984/Balangay-Of-The-Forgotten/releases/tag/Release)
2. **Extract** the contents to your desired location
3. **Run** `Balangay of the Forgotten.exe`
4. **Enjoy** your adventure!

```bash
# Alternative: Clone and run
git clone https://github.com/jhparente/balangay_of_the_forgotten.git
cd balangay_of_the_forgotten
# Extract and run the .exe
```
