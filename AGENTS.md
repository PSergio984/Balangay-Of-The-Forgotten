# Agent Guidelines

## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues managed via `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical five-role triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo layout (`CONTEXT.md` and `docs/adr/`). See `docs/agents/domain.md`.
